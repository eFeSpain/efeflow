What the analyser checks

        
Derived, never authored.

        
    
          
  • Shadowed a rule an earlier one already decides
    • 
          
  • Conflict overlapping DNAT with different targets
    • 
          
  • Merge rules differing only by port
    • 
          
  • Unused a set no rule consumes
    • 
          
  • Hardening a chain that never drops invalid
    • 
        

        
Rate-limited rules are excluded.

    •

Format
        

          

            
Atomic ruleset file

              
—

              
Single nft -f file with flush ruleset. Applies as one transaction; a syntax error leaves the running config untouched.

            

          

            
Incremental delta
Only the add / delete commands since the last export. Preserves counters on untouched rules.

            

          

            
systemd unit + /etc/nftables.conf
Drop-in bundle with nftables.service and a pre-apply validation hook.

            

          

            
Ansible / Terraform module
Templated resource with variables extracted from your sets and interfaces.

Include flush ruleset header

          
Preserve comments and rule handles

          
Apply 4 optimiser suggestions

          
Emit named counters
